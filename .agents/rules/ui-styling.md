# Frontend UI/UX & Typography Standards

Whenever building or refining UI components (especially upon reviewing user screenshots):

1. **Headings**:
   - Font: `'Playfair Display', var(--font-playfair), Georgia, serif`
   - Weight: `600` or `500`
   - Color: `#263A33` (forest green)
   - Sizes: Page H1 `28px`–`40px`, Modals/Sections `22px`–`28px`, Cards `15px`–`18px`

2. **Subheadings / Italic Accents**:
   - Font: `'Playfair Display'`, italic
   - Size: `13.5px`–`15px`
   - Color: `#56756D`

3. **Body & Controls**:
   - Font: `'Inter', var(--font-inter), sans-serif`
   - Size: `13.5px`–`14.5px`
   - Color: `#4A5568` or `#5A6E65`
   - Line-height: `1.5`–`1.6`

4. **Badges / Eyebrow**:
   - Font size: `10.5px`–`11px`, `700` weight, uppercase, `letterSpacing: 0.1em`–`0.15em`, color `#56756D`

5. **Spacing & Sizing**:
   - Avoid oversized padding (`p={8}`+) and huge margins (`mb={12}`)
   - Modals and cards should fit standard screens without awkward inner scrollbars (`p={4}`–`p={5}`)
   - Buttons: `38px`–`44px` height, rounded pill (`borderRadius="full"`), background `#56756D`, hover `#263A33`
